{{- if .Values.server.enabled }}
autodoc-server is deploying to {{ .Release.Namespace }}.

Its startup rebuild (LLM prose for every registered cluster) can take up to a minute — the
Deployment won't report Ready before that finishes:
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "homelab-autodoc.server.fullname" . }}

Reach it without ingress/Gateway API configured:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "homelab-autodoc.server.fullname" . }} 8000:{{ .Values.server.service.port }}

Then open http://localhost:8000/admin and run the setup wizard (GitHub or OIDC login).
